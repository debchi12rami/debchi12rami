## 🚀 Featured Project

### 🥗 [NutriVision](https://github.com/debchi12rami/nutrivision)
**AI-powered food recognition and calorie tracking from a single photo.**

Upload a meal photo, and NutriVision detects the foods with **YOLOv8**, estimates portions, calculates calories, and logs the meal to a daily dashboard. It includes user accounts with roles (client, nutritionist, admin) and consultation booking.
